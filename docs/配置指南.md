# MaiWeave 配置指南

[文档目录](README.md) · [使用手册](使用手册.md) · [项目首页](../README.md)

在 MaiBot WebUI 打开 MaiWeave 的插件配置，修改后点击「保存」。下面按界面的七个标签页介绍。日程、书籍、人物和纪念日的具体内容在扩展页面中管理，操作见[使用手册](使用手册.md)。

## 第一次配置

先确认生活时区和默认生活模型，再按你的使用方式选择作息、天气和交流对象。其余参数可以沿用初始值。

| 项目 | 去哪里填写 | 怎么选 |
| --- | --- | --- |
| 时区 | 角色与作息 → 角色设定 | 必填，默认 `Asia/Shanghai` |
| 兴趣和背景 | 角色与作息 → 角色设定 | 选填，背景留空时沿用 MaiBot 人格 |
| 作息 | 角色与作息 → 日常作息 | 开启后按生活安排休息；关闭后全天候交流 |
| 模型任务 | 模型设置 → 默认生活模型 | 必填，默认 `utils`，选择 MaiBot 已配置的任务 |
| 城市 | 天气与见闻 → 实时天气 | 开启天气时填写，默认「大庆」，请改成想使用的城市 |
| 交流对象 | 人物与纪念日 → 个人资料 | 使用主动消息和日期提醒时选择接收聊天流 |
| 更新间隔与容量 | 高级设置 | 按需调整，已有默认值 |

页面中的中文分组用于查找设置。表格标题括号内是 TOML 配置节，例如「角色生活（life）」中的 `timezone` 对应 `[life]` 下的 `timezone`，完整键为 `life.timezone`。

## 角色与作息

### 角色生活（life）

| 配置项 | 键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 启用生活引擎 | `enabled` | 开启 | 控制生活推进和对话工具 |
| 生活时区 | `timezone` | Asia/Shanghai | 用于日程、作息和相对日期 |
| 自主安排活动 | `autonomous` | 开启 | 空闲时由角色选择活动 |
| 身份与职业（选填） | `occupation` | 留空 | 在「角色设定」填写具体身份，例如初二学生、博士生或自由译者。留空时首次从人设读取；生成的课表或班次可在「日程与作息」调整。 |
| 兴趣爱好 | `interests` | 阅读、散步 | 例如阅读、散步，供模型选择活动时参考 |
| 生活背景 | `background` | 留空 | 补充角色的生活背景，留空沿用 MaiBot 人格 |
| 遵循日常作息 | `schedule_enabled` | 开启 | 关闭后全天候交流，已有约定继续执行 |
| 午睡期间保持安静 | `nap_quiet` | 开启 | 日间实际睡眠时保持安静；关闭后允许回复，夜间睡眠沿用作息规则 |
| 睡眠时普通群聊跳过 Planner | `sleep_skip_group_planner` | 关闭 | 夜间睡眠或静默午睡时跳过普通群消息（含 @），这些消息也跳过宿主历史。符合关键词唤醒条件时照常接话。 |
| 睡眠时普通私聊跳过 Planner | `sleep_skip_private_planner` | 关闭 | 开启后，关键词或概率唤醒成功时正常聊天。仍在睡眠静默时，本条普通私聊跳过模型判断和宿主聊天历史。 |
| 允许聊天唤醒 | `wake_enabled` | 开启 | 聊天唤醒总开关；亲密人物可通过关键词或陪伴请求唤醒 |
| 私聊消息唤醒概率（%） | `private_wake_probability` | 0 | 普通私聊唤醒概率，午睡和夜间共用。默认每轮判断一次；开启跳过 Planner 后，每条普通来信判断一次。0 关闭，100 每次唤醒 |
| 唤醒关键词 | `wake_keywords` | 心情不好、难过、很低落、睡不着、想找人聊聊、陪陪我 | 可增删默认词，清空可关闭匹配 |
| 唤醒后保持清醒（分钟） | `wake_minutes` | 60 | 同一人物在群聊或私聊继续聊天会延长，道晚安时完成本轮回复后继续剩余睡眠 |
| 习惯入睡时间（整点） | `sleep_hour` | 23 | 夜间睡眠窗口开始时间 |
| 习惯起床时间（整点） | `wake_hour` | 7 | 夜间睡眠窗口结束时间 |

### 睡眠与梦境（dreams）

| 配置项 | 键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 启用梦境 | `enabled` | 开启 | 足够长的睡眠结束后生成一次梦境 |
| 梦境影响醒后心情 | `mood_effect` | 开启 | 允许梦境带来小幅情绪变化 |

作息、午睡静默和聊天唤醒的使用方式见[作息与陪伴](使用手册.md#作息与陪伴)。梦境最低睡眠时长在「高级设置 → 梦境生成条件」调整。

## 日程与成长

### 经济设置（life）

| 配置项 | 键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 起始存款 | `opening_balance` | 1500 | 第一笔收支前可调整 |
| 货币名称 | `currency_name` | 虚拟元 | 显示在钱包、车费和班薪后面 |
| 每月房租 | `monthly_rent` | 1600 | 填每月租金，住家或免租宿舍可填 0 |
| 每月生活杂费 | `monthly_utilities` | 180 | 填水、电、燃气与网络的月合计 |
| 交租日 | `rent_day` | 1 | 房租和杂费同日结算；短月份取最后一天 |

想让独立租房的麦麦每月存下一点，可以先把一个月的班薪加起来，再减去餐费、通勤和账单。例如书店每周上五天班，月收入约 3,480 元、日常花费约 1,300 元，房租填 1,600 元，水电燃气和网络合计填 180 元，月底大约能存 400 元。住家、住校或有人供餐时，按角色实际承担的费用填写。

| 配置项 | 键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 启用习惯学习 | `habits_enabled` | 开启 | 从完成的活动中学习时间和地点偏好 |
| 自主活动参考习惯 | `follow_habits` | 开启 | 在习惯时间优先选择已形成的活动 |

### 活动结果与目标（continuity）

| 配置项 | 键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 生成具体活动结果 | `outcomes_enabled` | 开启 | 独自模拟活动结束后生成细节、感受和下次接续内容 |
| 归并同类活动与学习偏好 | `semantic_learning` | 开启 | 使用 MaiBot 模型归并不同说法，依据已发生体验更新偏好 |
| 分解与推进长期目标 | `goal_planning` | 开启 | 将目标拆成可执行阶段，并依据活动结果推进 |
| 动态调整自主日程 | `adaptive_schedule` | 开启 | 天气、精力与临时事件改变时调整可变动安排 |
| 共同安排提前提醒（分钟） | `reminder_minutes` | 30 | 使用已有主动交流开关、时段和额度 |

### 日常阅读（books）

「每天自主阅读上限（分钟）」对应 `books.autonomous_minutes`，默认 90，可设 -1～480。当天已经读过的时间会计入上限，达到上限后自主安排选择其他活动；0 表示关闭自主阅读，-1 表示每日无上限。聊天和书架手动安排照常执行。单次默认最多 40 分钟，两次默认间隔 60 分钟，可在「高级设置 → 自主阅读节奏」调整。

### 生活日记与空间发布（diary）

| 配置键 | 默认值 | 用途 |
| --- | --- | --- |
| `diary.enabled` | 开启 | 自动选择写作时间并安排日记 |
| `diary.publish_mode` | `关闭` | 可选 `手动发布`、`日记完成后自动发布` |
| `diary.publish_visibility` | `好友` | 可选 `所有人`、`仅自己` |

需安装 MaiBot OneBot 适配器，并连接已登录的 SnowLuma 或 NapCat。客户端由连接信息识别，无需另填地址和密钥。SnowLuma 使用原生空间接口；NapCat 通过适配器读取 `qzone.qq.com` 的 Cookie，再由插件上传图片、发布随笔。Cookie 每次发布时获取，不另行保存；登录失效时请在 QQ 客户端重新登录。文案使用「模型设置 → 阅读与表达 → 空间文案」选定的任务，默认跟随默认生活模型，Token 计入「空间文案」。自动模式跟随当天写日记日程完成，每天发布一篇。文案编辑与连接检查位于日记详情。

## 天气与见闻

### 天气、订阅与搜索（world）

| 配置项 | 键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 启用实时天气 | `weather_enabled` | 开启 | 按所选来源更新实时天气 |
| 天气来源 | `weather_provider` | Open-Meteo | 可选 Open-Meteo、心知天气 |
| 心知天气 API 密钥 | `weather_api_key` | 空 | 选择心知天气时，填写控制台 API 密钥中的私钥 |
| 天气城市 | `city` | 大庆 | 天气与地点搜索共用的生活城市 |
| 国家或地区代码 | `country_code` | CN | 可选两字母代码，用于区分同名城市，例如 CN |
| 启用订阅资讯 | `news_enabled` | 关闭 | 读取已配置的 RSS 或 Atom 信息源 |
| 资讯订阅地址 | `feed_urls` | 空列表 | 每项填写一个 RSS 或 Atom 地址 |
| 启用 MaiBot 联网搜索 | `search_enabled` | 关闭 | 使用 MaiBot 模型管理中配置的联网服务和密钥 |
| 按城市自动搜索生活地点 | `places_enabled` | 关闭 | 自主活动按需求搜索当地场所，供日程选择 |

### 先连接 MaiBot 联网服务

搜索和网页读取通过 MaiBot 原生接口执行。插件读取当前 Bot 的联网任务分配；MaiBot 1.4 的服务定义沿用共享模型目录中的配置。

在 MaiBot「模型管理」中添加联网服务，并在「功能分配 → 联网搜索」选中它，再开启插件的「启用 MaiBot 联网搜索」。地点搜索、资料检索和网页读取共用此服务。

「天气与见闻」和城市地点面板会显示配置情况，以及上次实际调用的连接结果和时间。首次使用前显示「等待首次联网调用」。地点缓存有效时可直接使用；勾选「强制联网刷新」会重新检查配置并调用 MaiBot 搜索。自主规划在服务待配置时使用已有地点。

### 按城市搜索生活地点

心知天气可在[官网](https://www.seniverse.com/)申请免费版，实况提供天气现象与气温，并可读取三天预报；页面显示实际数据来源。体感温度、风速等字段按接口提供的内容使用。天气更新失败后按更新间隔重试，也可以在天气页手动刷新。

天气城市默认「大庆」，国家或地区默认「CN」。在插件配置的「天气与见闻」中开启「按城市自动搜索生活地点」，自主规划会先决定想做什么，再按活动需求调用 MaiBot 联网搜索。例如喝咖啡找咖啡馆、吃饭找餐厅、购物找商场；地点类别由活动决定。已有合适地点会直接复用。

「地点与移动」和「日程与作息」顶部显示城市、搜索进度和收录数量，也可填写「活动或地点需求」，点击「搜索并收录城市地点」。例如输入「找一家安静的咖啡馆读书」。留空时搜索适合日常休闲的公园、书店、咖啡馆；填写需求可查找其他场所。收录的地点出现在日程地点下拉框中，自主活动会参考当前城市的地点。选择地点记录可以查看来源。

地点搜索结果按城市和搜索词保存，插件重启后继续使用。成功结果缓存 30 天，空结果缓存 6 小时；命中缓存会直接使用已收录地点，节省联网搜索和地点整理的模型调用。页面显示「已使用缓存」。页面搜索默认使用缓存；勾选「强制联网刷新」后点击「搜索并收录城市地点」，可重新联网搜索并更新缓存。

新地点与「楼下街道」预设一段 15 分钟的模拟步行路线，可在「地点路线」中调整耗时和交通方式。关闭自动搜索后，自主规划使用原有生活地点；已收录记录仍可手动选择。

### 自主获取见闻

在「天气与见闻」配置页开启 MaiBot 联网搜索，并在 MaiBot「模型管理 → 功能分配 → 联网搜索」选择服务。再开启「自主获取见闻」，模型即可在自主日程中安排上网了解。

| 配置项 | 配置键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 自主获取见闻 | `world.explore_enabled` | 关闭 | 结合兴趣、订阅资讯与生活接续安排检索活动 |
| 关注主题 | `world.explore_topics` | 留空 | 留空时参考角色兴趣，也可填写本地活动、烹饪等主题 |
| 每日自主检索活动上限 | `world.explore_daily_limit` | 3 | 每次活动搜索一个主题，最多读取两篇网页 |
| 自主检索最短间隔 | `world.explore_interval_minutes` | 180 分钟 | 从上一次检索活动开始计算 |

自主活动次数包含已开始的失败活动，同一次活动的重试沿用原次数。页面手动检索与手动安排独立于自主次数。相同主题近期检索和网页读取会复用缓存：近期资讯为 6 小时，知识资料为 7 天。资料感想使用「模型设置」中的活动结果任务，默认跟随默认生活模型，调用用量计入「模型用量」。

## 聊天上下文

在「聊天上下文」选择信息量与内容分类；长度上限位于「高级设置 → 聊天上下文长度」。对应配置节为 `[context]`。

| 配置项 | 键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 群聊信息量 | `group_mode` | 1 · 精简 | 三档滑块：1 精简、2 均衡、3 丰富 |
| 私聊信息量 | `private_mode` | 2 · 均衡 | 三档滑块，独立于群聊设置 |
| 带入日程 | `schedule` | 开启 | 后续安排、日程变动和通知 |
| 带入人物与纪念日 | `people` | 开启 | 人物近况、关系、生活备注和近期纪念日 |
| 带入阅读笔记 | `reading` | 开启 | 点名书籍时优先使用对应笔记 |
| 带入生活接续 | `continuity` | 开启 | 未完话题、活动进度与长期目标 |
| 带入近期经历 | `experiences` | 开启 | 按话题和信息量选择近期经历 |
| 带入主动分享接话 | `sharing` | 开启 | 已发送的分享与后续回应，随主动交流功能启用 |
| 带入天气与地点 | `environment` | 开启 | 已开启的天气、资讯和城市地点信息 |
| 带入梦境与习惯 | `dreams` | 开启 | 已开启的梦境与习惯信息 |

**信息量**控制选取多少条记录、每条保留多少细节：精简侧重当前状态与相关话题，均衡补充近期生活，丰富带入更多细节。**字符上限**控制这些内容最终能占多少长度，提高档位后也会遵循上限。

上限包含 MaiWeave 规则、生活数据、标点与字段名，分别用于每次 Planner 判断和回复请求。MaiBot 人设、聊天历史及工具查询结果另计；字符数与 Token 数使用不同计量方式。调低可以节省聊天上下文，调高可以带入更多生活细节。

这些设置控制聊天时自动带入的内容。日程、阅读、日记和记录保存按各自功能设置继续运行；当前活动、睡眠规则与待确认修改持续提供给对话，更多记录可通过生活工具查询。模型会根据对话选择是否查询。

在「模型用量」页面底部查看最近 10 次注入明细，包括实际字符数、预算和内容组成。

## 交流与记忆

### 主动交流（proactive）

先在「人物与纪念日」选择接收聊天流，再开启主动交流。其他接收对象可填入「额外接收聊天流」。启用后每 10 分钟检查一次；「此刻生活」可查看发送次数、待跟进事项和最近结果。

每 10 分钟检查一次发送机会。同一聊天流的普通分享和提醒还要等发送间隔。麦麦答应在到站或做完某事后回你的消息，可以在下一次符合条件的检查时报信。

| 配置项 | 键 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 主动交流模式 | `mode` | 自然交流 | 下拉选择。自然交流由 Planner 判断是否开口；主动表达在内容判断通过后生成并发送，两种模式共用时段、额度和间隔 |
| 启用主动交流 | `enabled` | 关闭 | 根据重要经历请求 MaiBot 主动开口 |
| 作息问候 | `natural_greetings` | 关闭 | 随角色起床和睡前安排问候，使用所选主动交流模式；共用额度和间隔 |
| 允许群聊主动交流 | `group_enabled` | 开启 | 关闭后仅在选定的私聊主动开口。两种模式的群分享、配图、问候、提醒和群聊抓包一起关闭。 |
| 额外接收聊天流（选填） | `session_ids` | 空列表 | 人物资料中选定的聊天流自动加入；其他聊天流可填写 /maiweave 显示的 ID |
| 每日主动发送上限 | `daily_limit` | 4 | 分享与提醒按聊天流计数，分段算一次。日程回信单独计；设为 0 暂停主动发送 |
| 经历分享最低分 | `share_threshold` | 5 | 1～10 分，普通、熟悉关系及群聊按此门槛筛选；亲近私聊也会考虑3分及以上、有具体细节的日常经历。每轮最多三条候选，由模型选择一件或等待。判断理由显示在「此刻生活」。 |
| 主动交流间隔（分钟） | `cooldown_minutes` | 60 | 同一聊天流两次普通分享或提醒之间的最短间隔 |
| 允许开始时间（整点） | `start_hour` | 7 | 经历分享与提醒的时间窗口起点；早晚安跟随作息 |
| 允许结束时间（整点） | `end_hour` | 23 | 经历分享与提醒的时间窗口终点；早晚安跟随作息 |

想让麦麦更主动，可以从「主动表达、经历分享最低分 3、发送间隔 60 分钟、每日上限 4 次」开始调整。最低分越高，进入候选的普通经历越少。

主动表达选好内容后通过原生 Replyer 发送，自然交流交给 Planner 判断时机。作息问候使用所选模式。用户提到起床、面试等后续事项时，模型可保存跟进时间；在「成长与接续」中查看、修改时间和截止时间，默认截止为跟进时间后 24 小时。模糊时间采用的关心时间会写在事项内容中。

同一话题未发出时，按「未发送后重新判断间隔」再次选择时机，默认 60 分钟。主动交流每十分钟检查一次，并结合角色作息、人物近况和允许时段判断。在「此刻生活」的主动交流卡查看今日发送次数、待跟进事项、最早判断时间和最近结果。

到期事项会结束跟进，记录按「高级设置 → 数据保留」整理。

### 连接本机或远程记忆

启用 MaiBot 的 A_Memorix 后，在「原生记忆」开启连接并确认 MaiBot 网页地址。

- **MaiBot 1.4**：自动读取 `host/webui.json` 的登录凭据，复用并续期登录会话，按当前 Bot 访问人物画像和记忆。连接远程实例时，网页地址填写 `http://地址:端口/api/host/bots/BotID/proxy`，网页登录凭据填写登录密码；Bot ID 在 WebUI 的 Bot 管理中查看。
- **MaiBot 1.3**：自动读取运行目录 `webui.json` 或 `data/webui.json` 中的 `access_token`，按 MaiBot 规则转换为登录 Cookie。连接远程实例时，填写其 `maibot_session` Cookie。

用户讲述或聊天中确认的经历可以同步到原生记忆，后续更正也会一并更新。梦境和角色自主活动的经历保存在生活档案中。同步失败时，可以直接告诉 MaiBot「重试同步这条经历」。

普通经历发送前会进行一次「分享判断」。开启原生记忆连接后，判断会参考接收人的原生画像及当前聊天可用的相关记忆；兴趣资料由 MaiBot 原生记忆维护。判断输入共用已有群聊、私聊字符上限，使用默认生活模型，调用用量可在「模型用量」查看。判断为稍后再聊时，沿用再次判断间隔，并在主动交流卡片显示原因。

### 数据保留

| 内容 | 保留天数配置键及默认值 | 条数配置键及默认值 |
| --- | --- | --- |
| 运行记录 | `retention.log_days`：7 | `retention.log_count`：每类 1000 |
| 模型调用明细 | `retention.usage_days`：30 | `retention.usage_count`：10000 |
| 已结束日程 | `retention.plan_days`：90 | `retention.plan_count`：2000 |
| 普通经历 | `retention.experience_days`：180 | `retention.experience_count`：3000 |
| 网络资料 | `retention.world_days`：30 | `retention.world_count`：每类 300 |
| 生活图片 | `retention.image_days`：90 | `retention.image_count`：合计 500 |

「每日自动清理」对应 `retention.enabled`，默认开启。日程修改、经历修订、关系变化、目标分解和偏好依据各保留最近 10 条，通过 `retention.history_count` 调整，设为 0 时保留全部历史。偏好分数和累计样本数独立保存。

钱包流水和生活费申请分别使用运行记录的天数和条数。最近一笔流水、未还借款的到账凭据、待缴账单关联的申请、待报信的还款及保留日程的入账凭据会继续保存。计算一周饭钱用到的日程和现行排班的最近一次工作进展也会留下。

书籍上传中断后，从最后一次写入文件算起，超过运行记录保留天数就会清理临时文件。活动念头和淡出的习惯沿用普通经历的限制，已约好后续日期或仍有日程关联的念头会留下。手动忽略的习惯会记住你的选择。

清理先按天数，再处理超过数量的旧记录。运行记录、用量、日程和普通经历的天数或条数设为 0 时，关闭对应限制；两项都为 0 时长期保留。网络资料保留天数至少为 1，条数至少为 20。

7 分及以上的重要经历、手动设为长期保留的经历，以及正在使用的活动关联会继续保留。日程至少覆盖习惯观察期，交流回执覆盖当天额度和当前发送间隔。日记正文、空间发布记录、阅读笔记和梦境长期保存。配图另按时间、数量和容量清理，容量配置 `retention.image_max_mb` 默认 1024 MiB（1 GiB），三项配图限制均至少为 1。

Token 统计按当前保留的调用明细汇总。网络资料包括资讯、检索、网页和地点搜索缓存；已收录地点与形成的经历继续保存。

聊天安排核对过的进度至少保留一天，待处理的聊天继续排队。实际发出的主动分享保留两天的接话窗口。插件重启后，上次中断的页面任务和资料写入也会进入清理范围，需要你确认的资料仍可继续处理。

「经历与记忆 → 数据保留与清理」可以预览和手动清理。SQLite 会复用释放的空间，清理后数据库文件大小可能保持原值。MaiBot 原生记忆由 MaiBot 管理。

### 插件信息

`plugin.config_version` 用于识别配置格式，由插件管理。日常修改通过 WebUI 配置页保存；迁移到另一台机器时一起保留配置文件与插件数据目录。

### 空间随笔与聊天图片

在「模型设置 → 图片生成服务」填写接口和模型，在「插件配置 → 模型设置 → 图片用途」分别设置「空间随笔自动配图」和「聊天追问发图与主动分享配图」。每篇空间随笔保留一张配图。

| 配置 | 怎么填 |
| --- | --- |
| 启用图片生成服务 | 默认关闭；控制所有新图片生成 |
| 聊天追问发图与主动分享配图 | 默认关闭；控制追问发图和主动分享配图 |
| 空间随笔自动配图 | 默认关闭；开启后，空间文案写好后自动出图 |
| 生图接口地址 | 填写所选接口格式对应的基础地址，例如 OpenAI 兼容服务的 `https://api.openai.com/v1` |
| 生图 API Key | 服务提供的密钥 |
| 生图模型 | 服务实际支持的图片生成模型名称；初始值为 `gpt-image-1` |
| 空间随笔与测试风格 | 用于空间随笔配图和配置测试，默认细腻柔和的二维日常插画，可修改或留空 |
| 聊天图片风格 | 用于追问发图和主动分享配图，默认细腻柔和的二维日常插画，可修改或留空；修改后用于新生成的图片 |

在「模型设置 → 图片生成服务 → 出图尺寸」选横图、竖图、方图或服务默认。默认 1024×768，需要较高分辨率时可选 2048×2048 或自定义宽高。配置测试会显示请求尺寸和实际返回尺寸。原图保存在插件数据目录，页面使用缩略图，发到聊天或空间时按生成尺寸转为 JPEG。服务返回 Base64 图片或可下载的图片链接均可，图片格式支持 PNG、JPEG、WebP。运行 MaiBot 的容器需要能访问生图地址和返回的图片链接。手动配图也使用这里的服务设置。

配图保留设置在「高级设置 → 数据保留」：默认保留 90 天、最多 500 张、合计 1024 MiB（1 GiB）。空间随笔、聊天图片和已有日记图片共用上限，任一超出时从最旧的图片开始清理。每次生成后检查上限；开启每日自动清理后，还会每天清理过期图片与未被记录引用的遗留文件。正在生成、发布和等待核对的图片在操作结束后参与清理。

保存生图配置并开启图片生成服务后，点击插件配置页顶部的「测试生图配置」。测试会实际生成图片，显示测试日期、开始时间和已用时；生图请求超时为 180 秒，服务返回图片链接时，下载超时为 60 秒。完成后显示本次结果、总用时或错误原因，反馈在 30 秒后收起。测试使用正式出图尺寸，仅保留最近一张测试图，并纳入生活图片保留上限；调用计入「生图测试」用量。

「模型设置 → 阅读与表达 → 图片生成提示词模型」用于聊天配图，以及空间配图缺少提示词时的补充，默认跟随默认生活模型。空间自动配图由空间文案模型一次生成正文与提示词；手动填写的提示词沿用原文；开启角色卡时，模型会结合文案判断麦麦是否入镜。配置测试使用固定场景。单独编写提示词的调用计入「配图提示词」用量。

### 麦麦角色卡

在「此刻生活 → 角色与图片」开启角色卡，填写外貌设定和常用穿着。空间随笔与聊天共用这张卡。

| 配置 | 用法 |
| --- | --- |
| 启用麦麦角色卡 | 默认关闭，开启后根据画面内容使用角色设定 |
| 外貌设定（选填） | 最多 800 字，填写发型、发色、眼睛等稳定特征，例如「黑色齐肩发、棕色眼睛」 |
| 常用穿着（选填） | 最多 400 字，例如「米白色针织衫」，穿着会结合当前活动调整 |

想看书签、饭菜时，画面聚焦物件；想看麦麦做饭的样子时，人物画面会带上角色设定。空间自动配图在写文案时一并选择构图，聊天配图由「图片生成提示词模型」处理。外貌和穿着只加入生图提示词，聊天上下文沿用原有预算。

同一经历已有图片时继续复用，修改角色卡用于后续新图。生图配置测试仍使用茶杯与绿植的固定场景。图片接口格式在模型设置中选择。Gemini 使用所选比例和分辨率档位，OpenAI Chat 通过提示词指定构图，其余接口传递宽高。


角色卡还可以填写「参考图片地址」并开启「使用角色参考图」。可在「此刻生活 → 角色与图片」上传图片，或填写一张 PNG、JPEG 或 WebP 图片的 HTTP(S) 直链。人物入镜时，插件读取这张图并提交给已配置的生图服务，外貌以参考图为主，文字角色卡补充细节，动作与场景按当前生活内容生成。物件特写和固定生图配置测试仍走文字生图。已有图片继续复用。

点击「角色与图片」页面的「根据 MaiBot 人设生成角色卡」，会读取 MaiBot 的人格配置，使用「图片生成提示词模型」生成外貌、穿着草稿。结果直接填入外貌与穿着框，修改后点击页面底部保存；人设未写明的外貌会作为建议补充。此次文字调用计入「配图提示词」用量，图片服务关闭时也能使用。


「负面提示词」位于两个风格配置旁，空间、聊天和生图测试共用，留空可关闭。默认排除写实皮肤、3D、塑料质感、商业海报、角色立绘、畸形手指和水印等效果。插件按接口与模型支持情况传入负面提示词，参考图模式同样使用。默认风格按生活内容选择构图：人物画面自然随拍，物件或风景画面聚焦对应主体。


### 图片开关怎么配合

「启用图片生成服务」控制新图生成。关闭后，空间自动配图和试画停止；聊天图片开启时，当前聊天有可复用图片才向模型提供发图工具，工具只查询和发送已有图片。空间已有配图仍可查看和发布。

「聊天中展示生活图片」控制聊天发图。关闭后，追问发图工具和主动分享配图一起关闭。空间文字随笔、发布与日常聊天照常使用。

### 保存后试画一张

在「角色与图片」保存设置后，下方「试画一张」可以选择自拍或物件近景，填写场景并生成。试画使用聊天图片风格；自拍按角色卡和参考图开关生成，物件近景聚焦物件。试画沿用模型设置中的出图尺寸，点击预览可查看大图。

页面显示所用模型、测试日期、用时与请求超时。这里与模型设置中的「测试生图配置」共用最近一次结果：配置测试使用茶杯与绿植场景和空间随笔风格，角色试画使用你填写的场景和聊天风格。图片沿用高级设置中的保留与清理规则。

### 上传与管理参考图

进入「此刻生活 → 角色与图片」，选择文件并点击「上传 / 替换」。页面会显示当前图片，可直接替换或移除。上传时保持比例，最长边缩小到 1024 像素并保存为 JPEG，只保留当前一张；这张角色素材独立于生活图片的自动清理。

上传的图片优先于配置中的直链。移除上传图片后，有直链时改用直链；两者都为空时，新的人物配图会提示补充参考图。参考图开关与文字角色卡开关都开启后生效。已经生成的生活图片继续复用，新图使用当前参考图。

### 图片接口格式与设置位置

图片生成遇到连接超时、中断或 HTTP 429、502、503、504 时，每隔 3 秒重试，默认最多重试 3 次（加上首次请求，共最多 4 次）。在「插件配置 → 高级设置 → 图片生成重试」修改次数，0 表示关闭自动重试；沿用本次画面描述和参考图。聊天追问、主动分享、空间配图和生图测试共用此流程，界面显示重试进度；每次请求的超时单独计算。密钥、余额或参数错误直接显示失败原因。图片生成成功后执行一次发送，QQ 投递失败可再次请求发送已有图片。

模型设置保留图片服务总开关、地址、密钥、模型名、接口格式和连接测试；「图片用途」分别控制聊天配图与空间随笔自动配图。角色卡、参考图、画风、负面提示词统一在「此刻生活 → 角色与图片」编辑，点击页面底部保存后生效。升级时沿用原有设置；以后以此页面保存的内容为准。

| 接口格式 | 地址与参考图 |
| --- | --- |
| OpenAI 图片编辑 | 地址通常以 `/v1` 结尾；文生图走 `/images/generations`，参考图走 multipart `/images/edits` |
| 参考图随生成请求发送（豆包方舟、通义兼容） | 火山方舟直连填 `https://ark.cn-beijing.volces.com/api/v3`，通义或中转服务填提供方给出的兼容地址。物件近景和自拍都请求 `/images/generations`，使用角色参考图时随 JSON 的 `image` 字段发送。TOML 配置值为 `通义千问兼容接口`。 |
| OpenAI Chat 生图 | 地址通常以 `/v1` 结尾；走 `/chat/completions`，模型需支持输出图片 |
| Gemini 原生 | 填服务根地址；走 `/v1beta/models/模型名:generateContent`，参考图使用 `inlineData` |
| DashScope 多模态 | 填服务根地址，如 `https://dashscope.aliyuncs.com`；使用同步多模态生成接口，模型需支持该接口 |
| Unsloth 原生 | 填服务根地址，如 `http://localhost:8888`；先在服务中加载所填的图片模型。使用当前已加载模型，人物参考图走原生 reference 流程，按所选宽高输出 |

接口格式按服务提供的文档选择。Gemini 原生与 OpenAI Chat 转发使用不同请求格式；通义兼容接口与 DashScope 原生接口也分别选择。

负面提示词通常与画面描述一起提交。DashScope 支持时使用独立字段；Qwen Image 2.1 与 Wan 2.7 沿用文字描述。
