# 功能与数据说明

[文档目录](README.md) · [使用手册](使用手册.md) · [配置指南](配置指南.md)

这页说明一项安排怎样变成生活经历，以及这些记录如何用于聊天、日记和记忆。具体操作见使用手册。

## 一项安排如何进行

你可以在聊天里约麦麦读书、出门或一起看电影，也可以在「日程与作息」新建安排。开启自主活动后，麦麦还会结合时间、兴趣、精力和已有约定，安排自己的空闲时间。

| 日程状态 | 含义 | 可以做什么 |
| --- | --- | --- |
| 待进行 | 已排好时间，等待开始 | 修改时间、地点或取消 |
| 进行中 | 活动正在进行 | 查看进度、暂停或取消 |
| 已暂停 | 活动暂停，记录保留 | 继续活动或取消 |
| 需要调整 | 固定活动与其他安排或出行时间冲突 | 修改时间、地点或路线 |
| 等待确认 | 共同安排等活动已到结束时间，等待实际完成情况 | 在聊天里说明做了什么，补充经历 |
| 已完成 | 已记录完成结果 | 回看感想、补充或更正细节 |
| 已取消 | 安排已取消，历史记录保留 | 查看取消经过；实际发生过的部分仍可补录经历 |

独自模拟活动结束后会整理结果；一起约好的事由聊天中确认的情况形成经历。活动的地点、天气、阅读内容和感想，会参与之后的聊天与日记。

重新加载插件后，会按已有日程和经过的时间更新进度与身体状态。活动改变时重新考虑接下来的安排，情况相同时按配置间隔检查。

## 计划与经历分别记录

| 内容 | 记录的是什么 | 例子 |
| --- | --- | --- |
| 计划 | 准备做的事 | 明晚八点一起看电影 |
| 用户陈述 | 你讲述的已发生事情 | 昨晚看完了电影，中途停电了一会儿 |
| 交互观测 | 当前交流中已经确认的互动，附依据 | 一次已确认的约定或交流结果 |
| 模拟经历 | 角色在生活引擎中独自完成的活动 | 午后散步、做饭的过程与结果 |

补充或更正经历时，原来的来源类别和修订历史会保留。已关联的日程、作品进度也会使用修订后的内容。

书架阅读记录使用「交互观测」来源，保存已读取的正文范围，并分别展示内容摘要、原文摘句和角色读后感。

天气和城市资料来自接入服务，阅读内容来自上传的书籍；角色的出行、作息和身体状态由生活引擎模拟。经历页面可以查看具体内容与来源。

## 聊天怎样用上生活记录

普通聊天会根据当前话题带入生活状态、人物近况、相关日程、阅读笔记和近期经历。群聊与私聊的信息量分别配置，完整记录也可以通过对话工具查询。

聊天提出的新安排会写入日程，日程里的结果又会用于后续交流。双方说定的角色调休、请假和临时改期，会保存原话依据、所属聊天流和有效时间。自主活动参考这些约定；日程修改沿用已有的时间冲突与出行处理，当天的临时变化保留其他日期的重复规则。读了一半的书和没完成的作品会保留进度，长期目标可以按阶段推进。

`/maiweave` 等状态指令直接展示查询结果。指令和状态回复按管理消息处理，聊天观察、历史上下文和 Planner 跳过这次查询。自然语言问“今天做了什么”则照常进入聊天。

人物近况按 MaiBot 人物身份关联，因此同一个人在群聊和私聊中的“去忙了”“准备睡了”等状态可以接续。各会话中的安排和资料按所属聊天流使用，公共自主活动与角色身体状态由各聊天流共享。

## 主动交流与普通回复

普通回复跟随 MaiBot 当前聊天流程，并参考麦麦的睡眠静默规则。主动交流会另外检查生活状态、接收对象、时间、间隔、额度和可分享内容。

生活经历在发送前会参考最近聊天和实际发送内容判断新意，明确的到期提醒继续按提醒流程处理。

- **自然交流**：将候选话题交给 MaiBot Planner，结合当前聊天决定是否开口。
- **主动表达**：选好内容后调用 MaiBot Replyer 生成并发送。

两种模式都按实际发送结果计算次数，分成几条发出的同一次回复计一次。主动交流卡片可以查看模式、接收对象、今日次数、等待事项和最近原因。开启作息问候后，早晚安随睡眠安排寻找时机。

## 原生记忆与生活档案

人物画像和通用记忆使用 MaiBot 的 A_Memorix。MaiWeave 通过记忆连接读取人物资料，并按用户操作同步经历或修改画像。

用户讲述与已确认互动形成的经历可以同步到原生记忆，后续修订也会更新对应内容。角色模拟经历、梦境、书籍与阅读进度保存在 MaiWeave 的生活档案中。

写入人物资料、纪念日或记忆时，会比较已有内容。相容的补充直接保存；出现矛盾时，页面列出差异供你修改或确认。

## 数据保存在哪里

生活记录存放在 MaiBot 为插件分配的数据目录，通常为 `data/plugins/ilworkcn.maiweave/`。其中包含生活数据库、上传的书籍原文件和解析正文。备份时保留整个目录和插件配置，操作见[数据与备份](使用手册.md#数据与备份)。

模型调用明细、运行记录和普通经历按「高级设置 → 数据保留」整理。日记、空间发布记录、阅读笔记和梦境长期保存。MaiBot 原生记忆由 MaiBot 管理。

## 外部服务与接入

| 功能 | 使用的服务 | 去哪里设置 |
| --- | --- | --- |
| 生活规划、阅读、日记等 | MaiBot 模型任务 | 插件配置 → 模型设置 |
| 天气与城市定位 | Open-Meteo | 插件配置 → 天气与见闻 |
| 搜索、网页读取、城市地点资料 | MaiBot 已配置的联网服务 | MaiBot 模型管理与插件天气设置 |
| 人物画像与通用记忆 | MaiBot A_Memorix | 插件配置 → 交流与记忆 |
| QQ 空间发布 | 统一 QQ 连接器连接的 SnowLuma | 连接器及插件生活日记设置 |
| 给其他插件提供状态 | MaiBot 跨插件 API | 调用方声明 `api.call` 能力 |

其他插件可以读取 `get_life_status` 和 `evaluate_behavior`。这两个 API 只返回当前状态与判断，查询过程保持生活记录原样。参数、字段、时间含义和示例见[只读状态 API](只读状态API.md)。
