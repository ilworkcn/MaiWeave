# 功能完成清单

版本：0.3.0。这里对应已明确讨论的功能范围，不将“最拟真”扩展为无限新增功能。

| 功能 | 实际行为 | 入口与验证 |
| --- | --- | --- |
| 对话与日程双向交互 | 新增、修改、取消、暂停、恢复；临时事件重排自主安排 | 日程工具、生活日程页、日程与冲突测试 |
| 结构化持久经历 | 区分计划、陈述、观测、模拟与梦境，支持细节修订 | 经历工具、经历与记忆页、记忆接口测试 |
| 原生记忆 | 使用 A_Memorix 公开 HTTP 接口查询和同步非模拟记录 | 记忆配置与同步操作；未另建通用记忆数据库 |
| 自主生活 | 人格、身体状态、目标、习惯、偏好和持续事项共同参与 | 周期推进与 Planner/Replyer 上下文 |
| 睡眠与梦境 | 作息、精力恢复、梦境档案与醒后感受 | 睡眠与梦境页 |
| 天气与外部世界 | 真实天气、预报、订阅、联网搜索、网页阅读 | 天气与见闻页；天气影响活动调整 |
| 空间与连续出行 | 地点图、最短耗时路线、分段移动、后续路线重算、异地恢复返程 | 地点与移动页、整条时间线测试 |
| 重复日程 | 日、周、月规则，间隔、截止日期、跳过一次、整条修改 | 重复日程页 |
| 具体活动结果 | 模拟过程、进度、感受、作品对象和下一次接续 | 生活接续页；不会覆盖用户修订或补造现实细节 |
| 习惯与偏好 | 语义归并、不同日期观察、体验评分、忽略与过期 | 习惯与成长、生活接续页 |
| 持续情绪与关系 | 事件影响逐渐衰减，未解决事项持续影响并可关闭 | 情绪与关系工具、生活接续页 |
| 阶段目标 | 自动分解、按有效进展推进、失败后继续当前阶段、调整剩余阶段 | 生活接续页、整轮生活推进测试 |
| 主动聊天 | 经历分享、共同安排提醒、完成情况关心、话题接续 | 宿主主动交流能力；请求去重、时段与额度 |
| 中文 WebUI | 全中文配置标签与类型控件，九页状态与操作工作区 | 官方 v2 页面模型与真实 SDK 校验 |

代码测试覆盖普通业务、失败结果、重启持久化和完整生活推进。真实模型的具体文字、平台发言决策与实际宿主页面显示需要在部署实例中验收；本地未配置可运行的 MaiBot 实例，因此没有将接口测试标作实机联调。
